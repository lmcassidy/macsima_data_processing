📋 JSON Format Requirements

Your JSON file must contain these top-level fields:

  • experiments - Array of experiment objects
  • procedures - Array of procedure objects with blocks
  • racks - Array of rack objects
  • rois - Array of region of interest objects
  • samples - Array of sample objects

Example structure:

{
  "experiments": [{"name": "Test", ...}],
  "procedures": [{"blocks": [...]}],
  "racks": [{"name": "Rack1"}],
  "rois": [{"name": "ROI1", "shape": {...}}],
  "samples": [{"name": "Sample1", ...}]
}
